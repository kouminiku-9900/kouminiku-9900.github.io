Super Local Video Shuffle Support

Last updated: November 12, 2026

Native version 1.1

Super Local Video Shuffle is a free app for sequential or shuffled playback of videos in a Mac folder and its subfolders. Version 1.1 requires macOS 14 or later. Its interface supports Japanese, English, Traditional Chinese, Korean, German, French, Spanish, Italian, and Portuguese (Portugal).

Playing videos

Choose a video folder with the folder button. Use the queue to select a video and the controls to change playback position, speed, volume, mute, or fullscreen. Supported containers are MP4, M4V, MOV, MKV, and WebM; playback also depends on the video and audio codecs inside the file.

Troubleshooting

If a folder cannot be reopened after restarting, select it again to renew access. For a damaged or unsupported file, retain the original and convert a copy to H.264 video with AAC audio in MP4, or continue to another video. Check the ReplayGain setting if volume differences are a concern.

Updating from the previous version

Normal-player settings are imported automatically. You can also select the old config.json using Import previous settings in Settings. Version 1.1 does not include Private Vault. Existing Vault data is not deleted, but cannot be opened in this version. If you use Vault, export videos you need with the previous version before updating.

Libraries and source

Open Settings > Third-party libraries to view library names, versions, and full licenses. Corresponding source archives, modification patches, application source, and build and library-replacement instructions are included in the app.

Version 1.0.x documentation (includes features not present in native version 1.1)

Super Local Video Shuffle plays user-selected local video folders and includes an encrypted Private Vault for selected videos.

Common Checks

  • If a folder no longer opens after restart, choose the folder again so macOS can refresh permission.
  • If a video will not play, convert it to MP4 using H.264 video and AAC audio.
  • If Private Vault unlock fails, confirm that protected storage is available for the current macOS user. If a Touch ID prompt appears, complete it and try again.

Contact

For issues, feedback, and feature requests, email kouminiku@gmail.com. This is the functional support contact available to all users.

When reporting a problem, include the app version, macOS version, what you expected, what happened, and the steps needed to reproduce it. Screenshots and crash logs are helpful, but remove personal information and unnecessary local file names before attaching them.

Security and privacy reports

For a possible Private Vault vulnerability, unintended decryption, or disclosure issue, do not post details publicly. Use the subject “Security Report” and report it privately by email. Do not send actual sensitive videos, vault keys, passwords, or personal data.
